# flappy-bird-assets

Sprites and sound effects for building a Flappy Bird clone.

## Contents

- `sprites/` — birds (yellow, red, blue; up/mid/down flap), pipes (green, red), day and night backgrounds, ground, score digits 0–9, "get ready" message, and game over screen
- `audio/` — wing, point, hit, die, swoosh (WAV and OGG)
- `favicon.ico`, `screenshot.png`
